🔐 Sécurisation du calendrier

Créez votre code PIN. Il vous sera demandé à chaque ouverture, avant le mode d'emploi.

Force du code : —
  • Une lettre majuscule
  • Une lettre minuscule
  • Un chiffre
  • Un caractère spécial (! @ # $ % & * …)
  • 8 caractères minimum

🔑 Votre code de récupération

Notez-le en lieu sûr (papier, coffre) : après 3 erreurs de code PIN, il vous permettra de déverrouiller le calendrier. Il ne sera plus jamais affiché.

1Sécurité et code PIN

Le calendrier s'ouvre en trois étapes : code PIN → mode d'emploi → calendrier.

  • Le code PIN doit contenir une majuscule, une minuscule, un chiffre et un caractère spécial (8 caractères minimum). Les 👁️ yeux permettent de vérifier la saisie et la correspondance des deux codes.
  • Si vous cliquez Plus tard, vous pourrez ouvrir le calendrier 3 fois sans code. Ensuite la création du code devient obligatoire : sans code, plus d'accès au calendrier.
  • Pour modifier ou supprimer votre code : 🎨 Personnaliser → onglet Sécurité.
  • Code de récupération : à la création du code PIN, un code de 12 caractères (ex. K7P2-M9X4-AB3C) vous est remis une seule fois — notez-le en lieu sûr. Après 3 erreurs de code PIN, l'application vous propose de déverrouiller avec ce code de récupération. Après 3 erreurs sur le code de récupération, il ne reste qu'une solution : créer un nouveau code PIN avec un nouveau code de récupération — l'ancien code PIN et l'ancien code de récupération sont alors définitivement supprimés de la mémoire de l'application (vos données sont conservées).
  • Modifier le code PIN ou cliquer 🔑 Générer un nouveau code de récupération (onglet Sécurité) efface toujours l'ancien code de récupération et en affiche un nouveau, une seule fois.

2Les vues : quotidien, hebdomadaire, mensuel, annuel, agenda

  • Quotidien : une journée, horaires de 7 h à 23 h en semaine, 8 h à 21 h le week-end (colonnes en rouge), par tranches de 30 minutes. Les flèches ◀ ▶ en haut et les flèches clavier ← → font défiler les jours.
  • Hebdomadaire : la semaine complète (lundi à dimanche) avec le numéro de semaine, par tranches de 30 minutes. Flèches ◀ ▶ ou ← → pour naviguer semaine par semaine.
  • Mensuel : le mois avec les numéros de semaine dans la colonne de gauche. Les flèches ◀ ▶ (ou ← →) passent au mois précédent / suivant ; la ligne de la semaine active est surlignée et un clic sur son numéro ouvre cette semaine en vue hebdomadaire. Cliquer un jour ouvre ce jour en vue quotidienne.
  • Annuel : les 12 mois de l'année. Les jours fériés apparaissent en orange vif, les week-ends en rouge. Choisissez l'année avec 📅 (2027 à 2051).
  • Agenda : la liste chronologique de tout (rendez-vous, anniversaires, gardes, récupérations, vacances scolaires, vacances personnelles, jours fériés), regroupée par mois avec compteurs, cartes colorées par type, filtres et recherche. Le bouton ＋ 🎂 Anniversaire permet d'entrer directement un prénom et une date. L'impression (🖨️) donne une liste propre et continue.
  • 📝 Notes : ajoutez des notes horodatées depuis les vues Quotidien et Hebdomadaire (sélection du jour de la semaine). La vue Mensuelle affiche le récapitulatif des notes du mois. L'onglet Récap Notes liste toutes les notes, de la plus ancienne à la plus récente : corbeille avec confirmation pour supprimer une note, suppression groupée des notes antérieures à une date choisie, et bouton 🖨️ Imprimer les notes. Toute suppression agit sur toutes les vues à la fois.
  • Stats 📊 : l'onglet Stats résume l'année en cours (gardes avec garde du Nouvel An automatique, jours de récupération, rendez-vous par importance, anniversaires, jours de vacances personnelles, notes) avec un tableau mois par mois. Changez d'année avec ◀ ▶ ou 📅.
  • Recherche globale 🔍 : le bouton 🔍 cherche partout (rendez-vous, anniversaires, gardes, récupérations, vacances personnelles, notes, jours fériés, vacances scolaires). Cliquez un résultat pour ouvrir son jour.

3Créer, modifier et supprimer un rendez-vous

  • Créer : cliquez sur une plage horaire (à l'heure ou à la demi-heure) dans les vues hebdomadaire ou quotidienne. La fenêtre s'ouvre déjà pré-remplie avec la date et l'heure choisies. Un rendez-vous saisi dans une vue est automatiquement reporté dans les autres vues (quotidien, hebdomadaire, mensuel, agenda), à la même date, même heure, même importance.
  • Importance (surligneur de couleur) : Rouge pastel — importantBleu pastel — moyenCitron vert pastel — moins important
  • Modifier : cliquez sur un rendez-vous puis sur ✏️ (ou ouvrez-le depuis la vue agenda). Changez date, heure, durée, importance ou notes ; l'enregistrement met à jour toutes les vues.
  • Déplacer : glissez-déposez le rendez-vous (souris maintenue) vers une autre plage horaire du planning.
  • Répéter 🔁 : dans la fenêtre du rendez-vous, l'option Répéter crée une série chaque semaine (même jour), chaque mois ou chaque année (même date). Les occurrences s'affichent avec 🔁 dans toutes les vues et l'agenda. Modifier ou supprimer agit sur toute la série ; une occurrence n'est pas déplaçable (déplacez la série depuis sa première date). L'export ICS inclut la récurrence.
  • Supprimer : cliquez sur 🗑️. Une sauvegarde JSON vous est proposée avant toute suppression. La tâche peut aussi être marquée ✔ terminée avant suppression.
  • Anniversaires : ajoutez-les dans 🎨 Personnaliser → onglet Données (nom + jour/mois) ou directement depuis l'Agenda avec le bouton ＋ 🎂 Anniversaire (prénom + jour/mois). Ils se répètent chaque année et s'affichent en orange vif, gras et italique dans les entêtes des vues quotidienne, hebdomadaire et mensuelle. Ils sont exportés avec vos sauvegardes.

4Mode travail de nuit, plages de garde et récupération

  • Cochez 🌙 Mode travail de nuit dans la barre d'outils : le planning passe sur l'amplitude 18 h → 9 h du matin (jour J soir + nuit suivante), en quotidien, hebdomadaire et mensuel.
  • Plages de garde : un clic sur 🌙 (coin d'un jour en vue mensuelle) ou le bouton ＋ Garde planifie une garde 18 h → 9 h le lendemain.
  • Garde du Nouvel An : les plages de garde du 31 décembre (18 h) au 1er janvier (9 h) sont créées automatiquement pour chaque année, du 31/12/2027 au 01/01/2051 inclus.
  • Jours de récupération : les 2 jours suivant chaque garde sont marqués 💤 Récupération dans toutes les vues.
  • Récupérations manuelles : pour les longues séries (ex. 14 jours de travail d'affilée puis 14 jours de récupération), cliquez sur 💤 dans la barre d'outils et planifiez une plage de 1 à 60 jours (liste modifiable dans la fenêtre). En vue mensuelle (mode nuit), le bouton 💤 / ❌ en haut à droite de chaque jour ajoute ou retire un jour isolé. Ces jours s'ajoutent aux 2 jours automatiques et apparaissent dans les vues quotidienne, hebdomadaire, mensuelle, l'agenda, l'export ICS et les rappels du jour.
  • Demi-heures : les tranches de 30 minutes s'appliquent aux horaires classiques (7 h → 23 h et 8 h → 21 h). Le mode nuit reste à l'heure.
  • 🏖️ Vacances personnelles : cliquez sur 🏖️ dans la barre d'outils et planifiez une période (date de début + date de fin). Chaque plage s'affiche en vert pastel avec le mot Vacances sur tous les jours concernés dans les vues quotidienne (bandeau), hebdomadaire (colonne verte) et mensuelle (jours verts), ainsi que dans l'agenda, les rappels du jour, l'export ICS et les sauvegardes JSON. La liste des périodes est modifiable dans la fenêtre.
  • 🏫 Zones de vacances scolaires : dans la barre d'outils, cochez ou décochez les zones A (rouge), B (jaune) et C (bleu clair) pour choisir celles affichées dans les vues mensuelle et annuelle. Le réglage est aussi dans 🎨 Personnaliser → Vacances scolaires.

5Vacances scolaires des zones A, B et C

  • Les vacances scolaires sont visibles par défaut : dans la barre d'outils, les cases A B C (🏫 Zones) cochent les zones affichées — A en rouge, B en jaune, C en bleu clair. Chaque barre couvre la période complète, du premier au dernier jour de vacances ; survolez-la pour voir les dates exactes et la reprise des cours.
  • Les barres apparaissent en vue mensuelle (bandeau sous le titre), en vue annuelle (mini-barres sous chaque mois) et dans l'agenda (chaque période y est listée, avec le filtre dédié 🏫 Vacances scolaires). En vue mensuelle et quotidienne, le badge 🏫 indique les zones concernées par jour.
  • Ce calendrier intègre les dates officielles publiées par arrêté au Journal officiel pour les années scolaires 2026-2027 et 2027-2028. Les années suivantes ne sont pas encore publiées par le ministère.

Comment mettre à jour les vacances scolaires pour les années suivantes ?

  • Chaque été (généralement en juillet), le ministère de l'Éducation nationale publie le calendrier scolaire de l'année N+2 sur education.gouv.fr et service-public.gouv.fr (rubrique « Vacances scolaires »).
  • Ouvrez 🎨 Personnaliser → onglet Vacances scolaires → ＋ Ajouter une période, puis saisissez : le nom (ex. « Vacances d'hiver »), la ou les zones concernées (A, B, C ou toutes), la date de départ en vacances et la date de reprise des cours. La période apparaît immédiatement dans le calendrier.
  • Conseil : après chaque mise à jour, faites une sauvegarde JSON (voir chapitre 7) pour conserver vos périodes personnalisées.

6Jours fériés, phases de lune et semaines

  • Les 11 jours fériés français sont en gras et en italique dans toutes les vues, et en orange vif en vue annuelle.
  • Les pleines lunes 🌕, premiers quartiers 🌓 et derniers quartiers 🌗 sont calculés avec la date correspondante : icônes dans les vues mensuelle et annuelle, liste détaillée dans la vue quotidienne et dans chaque mois de l'année.
  • Les numéros de semaine (norme ISO 8601) figurent dans la vue mensuelle et dans le titre de la vue hebdomadaire.

7Sauvegarde, restauration et feu tricolore

  • Sauvegarde automatique : chaque création ou modification est enregistrée instantanément dans votre navigateur. L'heure de la dernière sauvegarde s'affiche dans la barre d'outils.
  • Sauvegarde JSON (💾) : télécharge un fichier contenant rendez-vous, anniversaires, gardes et réglages. Il sert à changer d'ordinateur ou à récupérer vos données après un crash. Restaurez avec 📥 (import).
  • ✅ La méthode simple (recommandée) : sauvegarde directe sur votre carte micro SD : une carte micro SD s'utilise exactement comme une clé USB, branchée dans le pc ou via un adaptateur.
    1. Mettez la carte dans le pc (fente SD de l'ordinateur ou adaptateur USB).
    2. Une seule fois : dans votre navigateur, réglez l'emplacement des téléchargements sur la carte (Chrome ou Edge : menu ⋮ → Paramètres → Téléchargements → choisissez la carte SD). C'est la seule « manipulation » à faire, une fois pour toutes.
    3. Ensuite, un simple clic sur 💾 et la sauvegarde atterrit directement sur la carte. Terminé.
    4. Sur votre téléphone Android : cliquez sur 💾, le fichier arrive dans le dossier Téléchargements du téléphone ; ouvrez ensuite l'application Fichiers et déplacez-le vers la carte SD. À faire de temps en temps, sans stress : le rappel des 7 jours vous préviendra au bon moment.
  • 💾 Sauvegarder sur une clé USB, une carte micro SD ou un disque dur externe (pas-à-pas, méthode copie manuelle) :
    1. Branchez la clé USB / la carte micro SD / le disque externe.
    2. Cliquez sur 💾 : le navigateur télécharge mon-calendrier-pro-sauvegarde-….json.
    3. Dans le bandeau de téléchargement (en bas du navigateur), cliquez sur l'icône dossier ou « Afficher dans le dossier », puis copiez le fichier sur la clé ou la carte (Windows : lecteur E:, F:… · macOS : /Volumes/VOTRECLÉ · Linux : /media/vous/VOTRECLÉ).
    4. Idéal pour une clé « complète » : copiez-y aussi le fichier HTML de l'application et server.py (voir ci-dessous) : la clé devient alors un calendrier autonome utilisable sur n'importe quel ordinateur.
  • 🔄 Synchronisation multi-appareils, méthode 1 : le serveur server.py posé sur la clé (Linux, macOS, Windows, n'importe quel navigateur) : copiez sur la clé le fichier HTML de l'application et server.py, puis lancez le serveur : python3 server.py (Linux/macOS) ou py server.py (Windows, ou double-clic). Le navigateur s'ouvre tout seul sur http://127.0.0.1:8765 : chaque modification est écrite dans donnees.json sur la clé. Éteignez le serveur avec Ctrl+C. Débranchez la clé, rebranchez-la sur un autre ordinateur, relancez : vos données suivent la clé. Le serveur n'écoute que sur votre propre machine (127.0.0.1), rien n'est envoyé sur Internet.
  • 🔄 Méthode 2 : fichier lié (Chrome ou Edge uniquement) : 🎨 Personnaliser → Données → 🔗 Lier un fichier de sauvegarde et choisissez un fichier .json sur la clé USB : l'application y écrit vos données à chaque modification. Sur un autre ordinateur, « ↻ Réactiver » relance l'écriture.
  • ↩️ Annulation : après toute suppression (rendez-vous, note, anniversaire, garde, récupération, vacances) ou réinitialisation, cliquez sur ↩️ dans la barre d'outils ou Ctrl+Z : les 10 dernières actions sont annulables. La 🗑️ corbeille (🎨 Personnaliser → Données) garde aussi les 30 derniers éléments supprimés, restaurables un par un.
  • Rappel : si aucune sauvegarde n'a été exportée depuis plus de 7 jours, un rappel s'affiche à l'ouverture.
  • Export ICS (📤) : exporte vos rendez-vous vers Outlook, Google Agenda, Thunderbird ou l'application Calendrier d'Apple (fichier standard .ics).
  • Feu tricolore : 🟢 tout est OK, 🟠 avertissement (pas d'export JSON depuis plus de 30 jours, ou sauvegarde locale indisponible), 🔴 clignotant = danger (données jamais exportées ou échec de sauvegarde locale).

8Notifications et rappels

  • Au premier lancement, le navigateur vous demande l'autorisation d'afficher des notifications : cliquez sur Autoriser.
  • À chaque ouverture du calendrier, un rappel récapitulatif liste les rendez-vous du jour, les gardes et les anniversaires à venir.
  • Un rappel s'affiche 15 minutes avant chaque rendez-vous (durée modifiable dans Personnaliser → Notifications), tant que la page du calendrier reste ouverte dans le navigateur, même réduite.
  • Les notifications fonctionnent localement, sans internet : ni compte, ni abonnement, ni envoi de données. Sous Chrome, Firefox, Edge et Safari, ouvrez simplement le fichier téléchargé.

9Personnalisation et couleurs

  • Nom de l'application : il n'est pas figé, il est à vous. Cliquez directement sur le nom dans l'entête (ou 🎨 Personnaliser → Couleurs) pour le changer : Entrée enregistre, Échap annule. Le nom est conservé dans vos sauvegardes JSON.
  • 🎨 Personnaliser → onglet Couleurs : choisissez une couleur d'accent dans la palette, ou créez la vôtre à la pipette, puis cliquez 📌 Garder cette couleur : votre couleur est mémorisée dans votre palette personnelle et appliquée à tout l'interface.
