# 📅 Mon Calendrier Pro

**Un calendrier personnel complet, dans un seul fichier. Gratuit, sans compte, sans abonnement.**

Créé par **KamaOne** (signature **SG**).

---

## C'est quoi ?

Mon Calendrier Pro est une petite application qui tient dans un seul fichier HTML. Pas de compte à créer, pas de serveur, rien à installer : vous l'ouvrez dans un navigateur et elle fonctionne, sur Windows, Mac, Linux, Android et iPhone.

**Utilisation en ligne :** https://kamaone.github.io/mon-calendrier-pro/

Sur téléphone, ajoutez-la à l'écran d'accueil comme une vraie application :

- **Android** : menu ⋮ de Chrome → « Ajouter à l'écran d'accueil »
- **iPhone** : bouton Partager de Safari → « Sur l'écran d'accueil »

Après une première ouverture avec internet, l'application s'ouvre aussi **sans connexion**.

## Comment ça marche ?

- L'application est **un seul fichier** (`index.html`) : tout est dedans, il suffit de l'ouvrir.
- Vos données (rendez-vous, anniversaires, notes, réglages) sont enregistrées **uniquement dans le navigateur de votre appareil** : rien n'est envoyé sur Internet, aucun compte, aucune analyse, aucun pistage.
- La sauvegarde s'exporte en un fichier JSON (bouton 💾) et se restaure sur n'importe quel appareil (bouton 📥). L'export ICS (📤) permet de récupérer les rendez-vous dans Outlook, Google Agenda ou l'application Calendrier d'Apple.
- Hors connexion, un petit fichier technique (`sw.js`) garde l'application disponible dans l'appareil.

## Principales fonctions

- **Vues** : quotidien, hebdomadaire, mensuel, annuel, agenda, récapitulatif des notes, statistiques
- **Rendez-vous** : importance, rappels 15 minutes avant, répétitions (hebdomadaire, mensuelle, annuelle), glisser-déposer
- **Anniversaires**, **notes horodatées**, **recherche globale** 🔍
- **Jours fériés français**, **zones scolaires A/B/C**, **phases de lune**, **semaines ISO**
- **Mode travail de nuit** : plages de garde, récupérations
- **Vacances personnelles**, mode nuit, protection par code PIN avec code de récupération
- **Impression** propre au format A4 de chaque vue
